**Amended**: the CLI criterion names the command as the CLI takes it, `sonos -r ROOM balance [value]` (the room is the global `-r`, as for `volume`), not `--room` after the command (2026-11-04) — cited: the existing CLI's `-r/--room` option

**Description**: Balance is one number per room from −100 (all left) to +100 (all right), 0 centred, stored on the speaker as its channel volumes: left = 100 − max(0, b), right = 100 + min(0, b); read back as right − left. It belongs to the room, not its group (a grouped room keeps its own). `/api/rooms` says which rooms support it (`balance_supported`: the model is one of Five, Port, Amp, Play:5, Play:3, Connect, Connect:Amp, or the room's own speaker is one half of a stereo pair, i.e. plays the single channel `LF` or `RF`, which SoCo's `channel` reads from the topology; a Sub, surrounds or a soundbar don't count). `GET /api/rooms/{uid}/balance` reads it, `POST /api/rooms/{uid}/balance {"balance": n}` sets it on the room's own speaker. The Rooms view shows a Balance slider (left to right, the value said as "Centre", "Left 20" or "Right 62") and a Centre key on each room that supports it; dragging sends at most every 250 ms, as the faders do. `sonos -r ROOM balance [value]` reads or sets it.
