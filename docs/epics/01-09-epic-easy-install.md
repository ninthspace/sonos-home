**Acceptance Criteria**:

- ffmpeg and ffprobe resolve in this order: the config path, the copy bundled with the package (ffmpeg only), `PATH`, `/opt/homebrew/bin`, `/usr/local/bin`. A test places a fake binary at each level in turn and asserts the winner; a configured path that doesn't work is final even when a bundled copy exists. `[unit]`
  - Evidence: tests/test_config.py::test_binary_lookup_order_config_then_bundled_then_path_then_fallbacks (fake binaries at all five levels, the winner asserted as each higher level is withdrawn: config, bundled, PATH, first fallback folder, second), ::test_binary_found_in_fallback_dir_when_path_is_empty, ::test_a_configured_binary_that_does_not_work_is_final_even_when_a_bundled_one_exists and ::test_binary_missing_everywhere_is_none (full suite 597 passed) — red: "assert '…/path/ffmpeg' == '…/ffmpeg-bundled'" with the bundled level skipped (config.py find_binary); "assert '…/bundled/ffmpeg-bundled' is None" with a configured path that doesn't work falling through to the next level (config.py)
