Each browser check runs in a foreground tab of the user's Chrome through claude-in-chrome, and its Evidence names the URL. Where a check samples or counts, it does so with a script installed in the page with `javascript_tool` (a `setInterval` sampler, a `fetch` wrapper that timestamps, counts or holds requests); the check names which. Stories 2 to 9 all edit `src/sonos_cli/web/` (`app.js`, `style.css`, `index.html`), so `do` builds them one at a time. Every change keeps the Console look (docs/quick/01-quick-console-look.md): one set of tokens, visible keyboard focus, 375 px with no horizontal page scroll.
